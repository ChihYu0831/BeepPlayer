# BeepPlayer

## 專案簡介

使用者可以透過滑鼠點擊按鈕，或使用鍵盤快捷鍵來播放 Do、Re、Mi、Fa、Sol、La、Si、Do 八個基本音符。

---

## 功能介紹

### 1. 音符按鈕播放

程式介面中提供 8 個音符按鈕，分別代表：

| 按鈕 | 音符 | 頻率 |
|---|---|---|
| Do | C4 | 523 Hz |
| Re | D4 | 587 Hz |
| Mi | E4 | 659 Hz |
| Fa | F4 | 698 Hz |
| Sol | G4 | 784 Hz |
| La | A4 | 880 Hz |
| Si | B4 | 988 Hz |
| Do | C5 | 1046 Hz |

使用者點擊任一按鈕後，程式會播放對應的音符聲音。

---

### 2. 鍵盤快捷鍵播放

除了使用滑鼠點擊按鈕之外，也可以使用鍵盤快速播放音符。

| 鍵盤按鍵 | 對應音符 |
|---|---|
| A | Do |
| S | Re |
| D | Mi |
| F | Fa |
| G | Sol |
| H | La |
| J | Si |
| K | 高音 Do |

當使用者按下對應鍵盤按鍵時，程式會播放相對應的音符。

---

### 3. 音符焦點提示

當使用者點擊某個音符按鈕，或使用鍵盤播放某個音符時，該音符對應的按鈕會出現藍色框線，讓使用者可以清楚知道目前播放的是哪一個音符。

---

### 4. 視窗大小自動調整

程式會記錄視窗與各控制項的初始位置及大小。當使用者調整視窗大小時，按鈕會依照比例自動縮放與重新排列，讓介面在不同視窗大小下仍能維持整齊的版面。

---

### 5. 關閉確認

當使用者關閉程式時，系統會跳出確認訊息，詢問是否確定要關閉應用程式。

若選擇「否」，程式會取消關閉動作；若選擇「是」，程式才會正式結束。


---

## 操作說明

### 滑鼠操作

直接點擊畫面上的音符按鈕即可播放聲音。

例如：

- 點擊 `Do` 播放 Do
- 點擊 `Re` 播放 Re
- 點擊 `Mi` 播放 Mi

### 鍵盤操作

使用鍵盤上的 `A S D F G H J K` 來播放音符。

例如：

- 按下 `A` 播放 Do
- 按下 `S` 播放 Re
- 按下 `K` 播放高音 Do
